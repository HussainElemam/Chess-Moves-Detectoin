================================================================================
                         PROCESSING PIPELINE
================================================================================

Live Video Frame
    ↓
YUV420 → BGR (Color conversion)
    ↓
Resize & Downscale
    ↓
Detect Chessboard
    ↓
Perspective Warp (512×512)
    ↓
✅ RUN TFLITE MODEL (pieces_int8.tflite)
    ↓
Get 64 Piece Predictions
    ↓
Convert to FEN
    ↓
Check Stability (require 2+ consecutive frames)
    ↓
Save Frame Image + Log Entry
    ↓
Return FEN if stable change detected
    ↓
Backend broadcasts accurate game state ✅

================================================================================
                         MODEL DETAILS
================================================================================

Model File: pieces_int8.tflite
Model Type: Quantized INT8 (fast and efficient)
Input Size: Dynamic (depends on interpreter)
Output: 13 classes per square (12 pieces + empty)
Processing: Every 3rd frame (configurable)
Board Size: 512×512 pixels (perspective-corrected)
Threads: 3 (CPU optimized)
Min Stable Frames: 2 (configurable, prevents flickering)

Performance:
  - Inference time: 20-40 ms per frame
  - Effective FPS: 10-15 fps (with processEvery=3)
  - Memory peak: ~5 MB
  - Model size: 2-5 MB
